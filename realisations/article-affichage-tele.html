Contexte de la Mission

Au cours de ma première semaine de stage au sein de l'entreprise Huet / JH Industries, le Directeur des Systèmes d'Information (DSI) m'a confié une mission d'optimisation de la communication interne. Le besoin exprimé était d'afficher des statistiques, des indicateurs de performance et des tableaux de bord en temps réel sur un écran de télévision positionné dans la salle des ingénieurs réseaux.

L'objectif principal consistait à concevoir une application web capable de charger une liste d'URLs internes de supervision et de les afficher de façon intermittente, alternée et cyclique sans intervention humaine. J'ai mené à bien l'intégralité de ce projet en autonomie.

Choix Technologiques et Initialisation

Pour répondre à ce besoin d'application, l'environnement de développement reposait sur le framework Angular et le langage TypeScript. N'ayant jamais manipulé Angular auparavant, la première phase de mon travail a nécessité une auto-formation rapide afin de prendre en main la structure d'un composant standalone moderne et l'architecture globale du framework.

La solution imaginée exploite un fichier de configuration externe config.json. Ce fichier liste dynamiquement l'ensemble des sites à visiter ainsi que le temps d'affichage désiré pour chacun d'eux, offrant une grande souplesse d'administration pour la DSI sans avoir à recompiler le code applicatif.

Implémentation du Chargement Asynchrone

Dès l'initialisation du composant (ngOnInit), l'application effectue une requête HTTP pour récupérer les paramètres du fichier JSON. Pour bloquer proprement l'exécution en attendant la configuration, j'ai utilisé l'opérateur firstValueFrom d'RxJS afin de transformer l'Observable en Promesse native :

try {
  this.config = await firstValueFrom(this.http.get('./config.json'));
  console.log('Configuration chargée avec succès.');
} catch (error) {
  console.error('Erreur lors du chargement de la config : ', error);
  return;
}

Algorithme de Rotation Infinie

Une fois les données acquises, la méthode lancerRotation() prend le relais. Elle exécute une boucle while (true) chargée d'actualiser la cible de l'affichage. L'astuce algorithmique réside dans l'utilisation de l'opérateur modulo (%), qui permet d'incrémenter le compteur à l'infini tout en s'assurant qu'il revienne automatiquement à 0 dès que la fin du tableau de sites est atteinte.

Pour la gestion du temps, une fonction utilitaire attendre encapsule un setTimeout dans une Promesse, suspendant temporairement la boucle selon le délai extrait du fichier de configuration :

async lancerRotation() {
  let compteur = 0;
  const sites = this.config.sites;

  const attendre = (ms: number) => new Promise(resolve => setTimeout(resolve, ms));

  while (true) {
    console.log('Index actuel : ', compteur);
    
    const siteCourant = sites[compteur];
    const urlSite = siteCourant[0];

    this.iframeUrl = this.sanitizer.bypassSecurityTrustResourceUrl(urlSite);
    
    let dureeAttente = this.config.useBaseRefreshInterval 
      ? this.config.baseRefreshInterval 
      : siteCourant[1];

    await attendre(dureeAttente * 1000);

    compteur = (compteur + 1) % sites.length;
  }
}

Défi Technique : Protection XSS d'Angular

Par défaut, le mécanisme de sécurité d'Angular bloque l'injection dynamique d'URLs dans une balise <iframe> pour prévenir les failles de type Cross-Site Scripting (XSS).

Résolution : Pour contourner légitimement cette restriction dans notre contexte de confiance locale, j'ai injecté le service DomSanitizer de l'implémentation de la plateforme. La méthode bypassSecurityTrustResourceUrl(urlSite) a permis de marquer explicitement les URLs du JSON comme sécurisées pour le navigateur.

Déploiement et Bilan

Une fois les développements validés sur mon poste local, j'ai procédé au nettoyage du code et publié mes sources sur le GitLab de l'entreprise. Le livrable a été déployé avec succès sur le serveur de développement IIS (Internet Information Services) interne afin d'alimenter en continu le téléviseur de la salle réseau.

Cette première réalisation m'a permis d'asseoir de fortes compétences issues du Bloc 1 de notre formation : la Mise à disposition d'un service informatique par le biais du déploiement IIS, la Planification d'activités en gérant mon autonomie face aux délais ainsi que l'Organisation de mon développement professionnel via une démarche d'auto-formation rigoureuse sur Angular.
